🔬 BLOCOS — Whisper local + IA em 2 passes (Claude / GPT-4o / Gemini)

Análise por Blocos de 3 Minutos + Seleção Refinada em 2 Etapas

O vídeo é transcrito localmente com whisper.cpp (sem custo). A transcrição é dividida em blocos de 3 minutos. Um motor de IA (Claude, GPT-4o ou Gemini — configurável) analisa e pontua cada bloco em uma primeira chamada. Os blocos com maior potencial são rankeados e enviados para uma segunda chamada de IA que seleciona os clipes finais com timestamps precisos. FFmpeg corta em 9:16 e whisper.cpp gera as legendas localmente.

🔬 Por que 2 passes de IA? Em vídeos longos (30min+), enviar a transcrição inteira de uma vez sobrecarrega o contexto da IA e dilui o foco. A abordagem em blocos divide o problema: o 1º pass avalia cada segmento de 3 minutos independentemente e atribui uma nota de potencial viral. O 2º pass recebe apenas os melhores blocos (top 5) com a transcrição SRT original para extrair timestamps precisos — produzindo cortes mais acurados e relevantes.
🔌 APIs suportadas nesta opção Selecione o motor na aba ⚙️ Configurar:

• Claude (Anthropic) — claude-sonnet-4-6, 2 chamadas por vídeo.
• GPT-4o (OpenAI) — gpt-5.6-luna, 2 chamadas por vídeo.
• Gemini (Google) — gemini-2.0-flash, 2 chamadas por vídeo.

Transcrição (whisper.cpp) e corte (FFmpeg) são sempre locais — custo zero de API para essas etapas.
🔔
OneDrive Trigger + Baixar + Salvar na VPSOneDrive Trigger → Write Binary File

Monitora pasta configurada. Ao detectar um novo vídeo, baixa do OneDrive e persiste em /home/node/.n8n-files/ para processamento local.

Event: File Created | Folder: {{ config.onedriveFolderId }}
🎙️
FFprobe + Extrair Áudio → Whisper.cpp Transcrever CompletoExecute Command (×2) + Code Node

Mede duração (ffprobe), extrai WAV 16kHz mono do vídeo inteiro, e transcreve localmente com whisper.cpp (modelo ggml-large-v3-turbo.bin, 6 threads) gerando um .srt com todos os timestamps. Sem OpenAI. Custo $0.

ffmpeg -y -i "{{ $json.videoPath }}" -vn -acodec pcm_s16le -ar 16000 -ac 1 "{{ $json.audioPath }}" whisper -m /home/node/.n8n-files/ggml-large-v3-turbo.bin -t 6 -f "{{ $json.audioPath }}" \ -l pt -osrt -of "{{ $json.srtBase }}" -np && cat "{{ $json.srtPath }}"
📦
Dividir em Blocos de 3 MinutosCode Node (JavaScript)

Parseia o SRT completo e agrupa as entradas de transcrição em blocos de 180 segundos (3 min). Cada bloco contém: índice, start, end e o texto completo das falas do período — pronto para ser enviado à IA para análise.

// Saída: array de blocos de 3 min ex: [{ blockIndex: 1, start: 0, end: 183, text: "fala completa do bloco..." }, { blockIndex: 2, start: 183, end: 364, text: "..." }, ...]
🤖
IA — Analisar Blocos (1º Pass)HTTP Request → Claude / GPT-4o / Gemini

Envia todos os blocos de uma vez para o motor de IA configurado. A IA retorna uma nota 0–100 para cada bloco indicando seu potencial de Short viral (gancho forte, impacto emocional, ensinamento prático ou humor).

system: "Avalie cada bloco 0-100. Sem hook claro nos primeiros segundos → no máximo 40 pontos. Critérios: (1) hook nos 3s iniciais — obrigatório, (2) impacto emocional ou ensinamento, (3) potencial de retenção até o final. [{\"blockIndex\":1,\"score\":85,\"reason\":\"motivo\"}]" user: "Duração: {{ $json.duration }}s. Blocos: {{ $json.blocks }}"
📊
Ranking dos Melhores MomentosCode Node (JavaScript)

Parseia as notas retornadas pela IA, ordena os blocos do maior para o menor score e seleciona os top 5. Monta um resumo com os textos desses blocos e a transcrição SRT original para passar ao 2º pass de IA.

// Parse + ordena por score desc scores.sort((a,b) => b.score - a.score); const topBlocks = allBlocks.filter(b => topIdxs.has(b.blockIndex)); // → passa topBlocksSummary + srtContent para o 2º pass
🎯
IA — Seleção Final (2º Pass)HTTP Request → Claude / GPT-4o / Gemini

Recebe os melhores blocos + o SRT completo e seleciona de 5 a 8 clipes finais com timestamps precisos (em segundos). Cada clipe inclui hook (frase de abertura) e reason (justificativa editorial). Cortes sempre em pausas de fala.

system: "HOOK OBRIGATÓRIO nos primeiros 3s — sem hook = descartado. Duração: mín {{ min }}s, máx {{ max }}s, IDEAL 40–70s. Cortes SEMPRE em pausas de fala (nunca no meio de frase). Leia TODA a transcrição antes de decidir. [{\"start\":12.4,\"end\":68.9,\"title\":\"slug\", \"hook\":\"Frase exata de abertura\",\"reason\":\"...\"}]" user: "Melhores blocos:\n{{ $json.topBlocksSummary }} \nSRT completo:\n{{ $json.srtContent }}"
🗂️
Montar Clipes + Loop Over ItemsCode Node + Split In Batches (batchSize=1)

Parseia o JSON da IA, valida durações (dentro da janela configurada) e monta os paths de cada clipe. Loop processa 1 clipe por vez para evitar sobrecarga de CPU na VPS.

🎙️
[Se incluirLegendas] Extrair Áudio + Whisper.cpp do ClipeExecute Command (×2) + Code

Extrai apenas o trecho do clipe em WAV 16kHz mono e transcreve localmente com whisper.cpp, gerando o .srt do clipe com letras maiúsculas. Pulado se legendas desabilitadas.

✂️
FFmpeg — Cortar 9:16 (+ Legenda, se habilitado)Execute Command Node

Salva o _meta.json (hook + reason + score), recorta o trecho e converte para 1080×1920 (crop centralizado). Se incluirLegendas=true, queima a legenda do .srt com fonte Poppins.

ffmpeg -y -ss "{{ $json.clipStart }}" -i "{{ $json.videoPath }}" \ -t "{{ $json.clipEnd - $json.clipStart }}" \ -vf "scale=-2:1920,crop=1080:1920:..." \ -c:v libx264 -preset fast -crf 22 -c:a aac -b:a 128k \ "{{ $json.outPath }}"
📤
Upload Short + Metadados → OneDrive → volta ao LoopRead Binary File + OneDrive (×2)

Lê o short_NN_slug.mp4 e o _meta.json do disco, envia ambos para o OneDrive e volta ao loop até processar todos os clipes. Arquivos temporários são removidos após upload.
